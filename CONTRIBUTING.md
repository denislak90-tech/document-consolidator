# Contributing

Requires Node.js 22+. No dependency installation is necessary.

Run `npm test` and `npm run demo`. Add meaningful tests for new grouping logic and boundary handling.

Use synthetic fixtures only. Do not submit source documents, real inventory reports or customer/employer data. Keep report data out of issues and pull requests.

Changes must preserve read-only source behaviour unless a separately reviewed mutation design is explicitly introduced. Document implemented capabilities and limitations. Roadmap ideas are not release features.
